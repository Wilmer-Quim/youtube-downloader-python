# YouTube Downloader & Audio Converter en Python

**yt-downloader-python** es un script en Python que te permite descargar videos de YouTube (o enlaces compatibles) y convertirlos a audio en formato **webm** o **mp3**, usando `yt-dlp`. Es ideal para extraer lecciones, conferencias o cualquier video al que quieras extraer el audio.

---

## 📋 Características

- Descarga de videos usando `yt-dlp`  
- Conversión automática a **webm** o **mp3**  
- Manejo de errores básicos (cuando falla la descarga o conversión)  
- Organización en versiones (puedes tener diferentes versiones del script dentro del mismo proyecto)  
- Muy ligero y fácil de modificar

---

## 🔧 Requisitos

Para que el script funcione necesitas tener instalado:

- **Python 3.x**  
- La librería `yt-dlp`  
- **ffmpeg** (opcional pero recomendado para convertir a mp3)
